# Доступность материалов Арти Клиник для поисковых и ИИ-ответов

Эти изменения помогают поисковой системе прочитать и связать уже существующее
содержание. Они не гарантируют включение сайта в ответы Алисы AI и не означают
медицинского рецензирования текстов.

## Что добавлено

- Страницы услуг описаны как `MedicalWebPage`, связанная со стабильным `Service`
  и отдельной организацией `MedicalClinic`. Название, описание, адрес организации
  и издатель взяты из существующих данных сайта.
- `FAQPage` строится только из того же `service.faq`, который отображается в
  разделе «Частые вопросы». Убираются лишь маркеры выделения `**` и лишние пробелы.
  Ответы из других блоков и скрытые дополнительные вопросы в разметку не добавляются.
- На страницах мануальной терапии, иглорефлексотерапии и лечения грыжи появились
  обычные ссылки на существующие статьи по этим направлениям. Короткая подборка
  использует те же явные правила `seoTopics.ts`, по которым статьи ссылаются на услуги.
  Полный индекс блога в клиентский код не загружается. Эти ссылки не обозначают
  независимые медицинские источники или рецензирование.
- Проверка SEO сверяет количество и текст вопросов/ответов в JSON-LD с исходным
  HTML, идентичность страницы/услуги/клиники и наличие обычных ссылок на статьи.
  Существующие проверки пререндеринга, внутренних адресов, sitemap, robots и
  изображений сохраняются.

## Что остаётся редакционной работой

Для медицинских материалов нужны проверяемые источники, точные формулировки и
реальная профессиональная проверка. Если врач проверил конкретный текст, сведения
об авторе/рецензенте и фактическую дату проверки следует показывать посетителю и
только затем отражать в разметке. Нельзя автоматически приписывать врачу авторство
всего блога или выставлять сегодняшнюю дату проверки всем публикациям.

Имеющиеся профили врачей, документы, публикации и сведения об образовании остаются
самостоятельными доказательствами квалификации, а не доказательством проверки
каждой статьи. Коммерческие обещания результата и медицинские рекомендации требуют
отдельной проверки специалистом; этот технический этап их не подтверждает.

В Яндекс Вебмастере после публикации можно отправить изменённые страницы на
переобход и отслеживать отчёт «Видимость сайта в Алисе AI». Приоритеты клиники:
лечение межпозвоночной грыжи, иглорефлексотерапия и мануальная терапия.

## Проверка

`npm run build` создаёт HTML страниц и запускает `scripts/check-seo.ts`.
`npm run check:seo` проверяет уже собранный `dist` и `.cache/routes.json`.
